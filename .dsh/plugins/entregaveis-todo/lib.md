# Biblioteca entregaveis-todo (DSH)

Funções puras para mapear arquivos de Entregaveis/ a entregas do .dsh/entregaveis.json.

## Mapeamento

Converte padrões de caminho (ex.: "Entregaveis/Modelagem/*classes*") em expressões regulares para encontrar a entrega correspondente a um arquivo gravado.

No DSH, este mapeamento é feito manualmente pelo agente, consultando .dsh/entregaveis.json.
